# Запуск трафика

Состояние на 9 октября 2026. Что уже работает, что осталось включить руками и как провести первый тест.

## Что работает

- **Честный барьер.** С пейволлом аноним на закрытой главе видит цену и покупку («Купить книгу», «Все четыре книги»); вход встроен в оплату, ниже ссылка «Уже купили? Войдите». В оглавлении у закрытых глав замок.
- **Бесплатное чтение.** Сверх экспорта открыты гл. 2 «Сознательного отбора» и «Эры Архитекторов» (`content/free-chapters.json`). Теперь бесплатно: «Небесный код» 76 мин, «Академия багов» 97, «Эра Архитекторов» 54, «Сознательный отбор» 17 — у него по-прежнему меньше всего.
- **Подписка без аккаунта.** Форма под барьером, в конце бесплатных глав и на страницах опытов. Двойное подтверждение письмом, отписка по ссылке, подтверждённые получают письма о новых главах (`/api/admin/notify`). Сводка: `curl -H "x-notify-secret: …" https://neuralcosmology.com/api/admin/subscribers`.
- **Опыты как посадочные.** `/<lang>/experiments` и `/<lang>/experiments/<id>` — 17 опытов, у каждого свой адрес, превью, выход в главу (бесплатную — «Читать главу бесплатно»), подписка, другие опыты. В меню, подвале и sitemap.
- **События** (GA4, и тем же вызовом в Метрику и пиксели): `read_chapter`, `experiment_start`, `video_play`, `chapter_complete`, `generate_lead`, `sign_up`, `begin_checkout`, `purchase`, `share`, `login_start`. В GA4 ключевые события: `purchase`, `begin_checkout`, `generate_lead`, `experiment_start`, `chapter_complete`.
- **Согласие.** Вне ЕЭЗ/UK/CH аналитика и реклама разрешены; в ЕЭЗ — обезличенные пинги, пиксели не грузятся (баннера нет).
- **Серверная покупка.** После оплаты глава открывается, сервер записывает покупку и шлёт её в GA4 Measurement Protocol с тем же `transaction_id`, что и браузер. Ждёт секрета `GA_API_SECRET`.

## Что включить руками

1. **Почта.** Ключ в `~/.config/inite/mailgun.env` Mailgun не принимает («Invalid private key»). Нужен рабочий API-ключ и подтверждённый домен отправки. Затем:
   ```bash
   gh secret set MAILGUN_API_KEY          # ключ
   gh variable set MAILGUN_DOMAIN --body mg.neuralcosmology.com   # домен из Mailgun
   gh variable set MAILGUN_REGION --body eu   # только для европейского аккаунта
   ```
   После деплоя разослать подтверждения тем, кто подписался раньше: `curl -X POST -H "x-notify-secret: …" https://neuralcosmology.com/api/admin/subscribers`.
2. **GA4 Measurement Protocol.** В GA4 → Администратор → Сбор данных → принять «Подтверждение сбора пользовательских данных» (юридическое согласие, принимает владелец). После этого секрет создаётся одной командой (скрипт с токеном из `~/.config/inite/ga4.json`) и кладётся в `gh secret set GA_API_SECRET`.
3. **Пиксели.** Вписать ID в `src/content/pixels.ts` (Meta, VK, Reddit) и номер Метрики в `src/content/verification.ts` — только для каналов, которые запускаем. Метрика нужна Директу.
4. **ИИ-собеседник в читалке.** В секретах репозитория нет `ANTHROPIC_API_KEY` — на проде собеседник, скорее всего, выключен.

## Посадочные и метки

Ссылки в рекламе — всегда с UTM, GA4 разберёт их сам:

```
?utm_source=telegram&utm_medium=seed&utm_campaign=experiments-oct&utm_content=physarum
?utm_source=meta&utm_medium=paid&utm_campaign=latam-pt-test&utm_content=planaria-9x16
?utm_source=reddit&utm_medium=paid&utm_campaign=en-consciousness&utm_content=yarbus
```

| Куда вести | Зачем |
|---|---|
| `/<lang>/experiments/<id>` | холодный трафик с ролика: человек сразу трогает то, что видел |
| `/<lang>/experiments` | посевы и посты «17 опытов, которые можно запустить в браузере» |
| `/ru/read/celestial-code/ch02`, `/ru/read/bugs-academy/ch01` | читатели художественного и научпопа; длинное бесплатное чтение |

## Первый тест: две недели, 300–500 $

| Канал | Язык | Бюджет | Посадочная | На что оптимизировать |
|---|---|---|---|---|
| Посевы в Telegram (научпоп, 5–8 каналов по 20–40 тыс.) | RU | 150–250 $ | страница опыта или `/ru/experiments` | клики → `experiment_start` |
| VK Реклама, ролики 9:16 | RU | 50–80 $ | страница опыта | `experiment_start`, затем `generate_lead` |
| Meta, Бразилия и Аргентина/Мексика | PT/ES | 80–120 $ | `/pt|es/experiments/<id>` | `experiment_start` (ViewContent/кастом) |
| Reddit, r/consciousness, r/cosmology, r/Physics | EN | 50–80 $ | страница опыта | `experiment_start` |

**Что считать в конце каждой недели** (GA4 → Исследования, срез по `utm_source`/`utm_content`):

1. Стоимость `experiment_start` — сравнить креативы, слабую половину выключить.
2. Доля дошедших до `read_chapter` и `chapter_complete` — интерес к книге, а не только к игрушке.
3. `generate_lead` и `begin_checkout` на 100 посетителей — готовность платить.
4. `purchase` — пока покупок мало, решения принимать по пп. 1–3.

Ориентир на старте: ≥ 40 % посетителей страницы опыта запускают его, ≥ 8 % доходят до главы, ≥ 1,5 % оставляют почту. Ниже — менять крючок и посадочную, а не повышать ставку.
